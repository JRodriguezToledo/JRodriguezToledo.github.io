Selected work

Master's thesis: how delays spread through the air network

In progress, due December 2026

Flight delays do not stay where they start: a late aircraft delays the next flight, and the knock-on effect travels through airports and sectors. I am building machine and deep learning models that predict delays and how they propagate along the network, using EUROCONTROL data, so that operations and air traffic management stakeholders can decide better.

The work is advanced Python for the numerical results and visualisations, plus the technical documentation. I will share results here if the thesis allows it.

Try it: a sector fills up

A small in-browser version of the model in my AirTrafficOccupancy project. The numbers are illustrative, not results.

Thin lines are 30 random runs over two days. The white line is their average. Aircraft arrive faster in the morning and evening and each one leaves at a fixed rate. The orange line is capacity. The full Julia version runs 1,000 trajectories over one and three weeks and tracks the extra cost of congestion.

Projects on GitHub

  • Air-traffic sector occupancy

    Julia

    A stochastic model of how demand and limited capacity create congestion in a control sector. Kinetic Monte Carlo with an arrival rate that depends on the hour and the day of the week, ensembles of 1,000 trajectories, overload probability and the cost of congestion on busy and quiet days.

    View on GitHub (AirTrafficOccupancy)

  • Hospital readmission prediction

    Python

    Eight classifiers, from logistic regression to XGBoost, compared on 5,000 diabetic patient records. A cost matrix penalises missed readmissions, and models are chosen by cross-validated performance, with ROC curves, confusion matrices and feature importance.

    View on GitHub (HospitalReadmissionPrediction)

  • Character-level text prediction

    Python, TensorFlow

    A simple RNN, a GRU and a two-layer LSTM, each with and without self-attention, trained on Shakespeare to predict the next character. Six models in one reproducible notebook, with weights and training histories included.

    View on GitHub (Character-LevelTextPrediction)

  • The Greeks

    Python

    A sensitivity analysis of the Black–Scholes model: analytical Greeks, the trade-off between gamma and theta, dynamic delta hedging over 252 trading days, a gamma-squeeze Monte Carlo, and Greeks from a live SPY options chain.

    View on GitHub (TheGreeksOptionAnalysis)

  • Western US power grid

    Python

    How robust is a real power grid? Clustering, distances, centrality and community detection, compared against Erdős–Rényi and Barabási–Albert random networks.

    View on GitHub (PowerGridNetworkAnalysis)

  • 2D Ising model

    Julia

    Metropolis Monte Carlo on a periodic lattice: energy, magnetisation, heat capacity and susceptibility, the critical temperature and exponents, and finite-size scaling with data collapse.

    View on GitHub (2DIsingModel)

Built at work, not public

  • Support agent for business teams

    Grupo Viajes El Corte Inglés, MVP

    An LLM application with a retrieval-augmented generation system. Business workers ask it instead of reading long documentation, and technicians stop solving the same problem again and again: the agent either fixes it or gives the user the steps. I designed the evaluation pipeline (an LLM judge, evaluation of the retrieved sources, prompt engineering) and connected databases with SQL in BigQuery, documents, search engines and APIs, including through MCP and A2A. It runs on Google ADK, Gemini Enterprise and Azure, over 18 technical documents and about 9,000 historical support tickets.

  • Customer churn model

    Grupo Viajes El Corte Inglés, in production

    A customer-lifetime-value churn model that helps the Business department take strategy decisions based on sales probabilities. I tuned, calibrated and evaluated it in Databricks, and used feature analysis to find what drives the number of purchases before a customer leaves.
